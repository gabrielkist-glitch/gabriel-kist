O que é HTML?

O HTML é uma linguagem utilisada para criar a estrutura de um site. Com ele podemos colocar títulos, textos, imagens, links e vários outros elementos que aparecem em uma página da internet.

O que é CSS?

O CSS serve para deixar o site mais bonito. Com ele podemos mudar as cores, o tamanho das letras, colocar imagens de fundo e organizar os elementos da página.
